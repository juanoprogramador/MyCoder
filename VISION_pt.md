# MyCoder Vision

## Português

MyCoder é uma IDE baseada em terminal criada para desenvolvedores que gostam de construir, modificar e controlar suas próprias ferramentas.

O projeto é fundamentado em quatro pilares:

* Otimização
* Customização
* Integração
* Liberdade

O MyCoder adota uma filosofia terminal-first e keyboard-first.

O diretório atual é considerado o workspace padrão:

```bash
cd meu_projeto
mycoder
```

A experiência padrão deve ser minimalista, mas altamente configurável.

Toda funcionalidade relevante deve ser acessível através da Command Palette.

Linux e Termux são as plataformas de referência para desenvolvimento e testes.

O projeto será open source e projetado para receber contribuições da comunidade.
