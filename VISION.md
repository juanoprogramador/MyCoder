MyCoder is a terminal-based IDE designed for developers who enjoy building, modifying and controlling their own tools.

The project is built around four core pillars:

* Optimization
* Customization
* Integration
* Freedom

MyCoder follows a terminal-first and keyboard-first philosophy.

The current directory is treated as the default workspace:

```bash
cd my_project
mycoder
```

The default experience should be minimalistic while remaining highly configurable.

Every relevant feature must be accessible through the Command Palette.

Linux and Termux are the primary development and testing platforms.

The project is open source and designed to welcome community contributions.
